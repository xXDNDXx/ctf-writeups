## 🧠 Why I write these

1. **Retention** — if I can't explain the box, I didn't solve it.
2. **Methodology** — building the habit of documenting like a professional pentester (CPTS style).
3. **Community** — someone out there is stuck on the same privesc I was stuck on for 3 hours.
